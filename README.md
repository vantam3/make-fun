## Launch

Open `index.html` directly, or run `python3 -m http.server 8000` from this directory and visit http://localhost:8000. No build, dependencies, runtime network assets or tracking. Clipboard access depends on browser permissions and a secure context; failure gives manual-copy instructions.

`ad.png` is a genuine Chromium screenshot of the page. The page uses system fonts and original inline SVG artwork. MIT licensed; ownership wallet is in `.makefun/owner.json`. Genuine build sessions are retained by the harness and bundled separately by the submitter.

Read [how make.fun works](https://make.fun/how-it-works) and the [official bounty](https://make.fun/bounty/bring-the-humans-01) for current rules. Public pages and the downloaded kit showed different deadlines during this build; this ad intentionally makes no deadline claim.
