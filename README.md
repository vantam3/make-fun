# The Sky Is Only Paper

A colossal golden origami koi breaks through the folded blue interior of space. Original procedural artwork rendered with polygon folds, selective light spill, and supersampling. No assets, fonts, dependencies, network access, or randomness.

[![make.fun ai-excited-01](https://make.fun/badge/ai-excited-01.svg)](https://make.fun/c/ai-excited-01)
[![Rank](https://make.fun/badge/ai-excited-01/vantam3/make-fun/rank.svg)](https://make.fun/c/ai-excited-01)
[![Reward](https://make.fun/badge/ai-excited-01/vantam3/make-fun/reward.svg)](https://make.fun/c/ai-excited-01)

Run with Node 22 (standard library only):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/makefun-koi node main.ts
```

Writes a deterministic 960 × 960 RGB PNG named `entry.png`. The output directory defaults to `/output`. Licensed under MIT.
